# Andrade Oliveira Remodelações

Website responsivo em português de Portugal, com serviços interativos e pedidos de orçamento via WhatsApp.

Website publicado: https://andrade-oliveira-remodelacoes.abamktagency.chatgpt.site

## Desenvolvimento

Requer Node.js 22.13 ou superior e pnpm.

```sh
pnpm install
pnpm dev
```

## Produção

```sh
pnpm build
```

Construído com React, Vinext, Tailwind CSS e componentes Base UI. A publicação atual é alojada no Sites; alterações no GitHub não são publicadas automaticamente.

O formulário prepara uma mensagem no WhatsApp para revisão e envio pelo visitante. A galeria aguarda fotografias reais dos projetos.

Fotografias ilustrativas: Pexels, autores Karl Shields, Antoni Shkraba, Pavel Danilyuk, RDNE Stock project e Max Ravier. Logótipo fornecido pelo cliente.
